# Website

The Noctenna landing page: HTML, CSS and JavaScript, built with Vite.

```sh
cd site
npm install
npm run dev     # http://localhost:5320, also reachable from a phone on the same network
npm run build   # writes site/dist
```

## How it is put together

- **Sections**, in order: hero, How it works (`#ask`), Reopen watch (`#reopen`), Tools (`#tools`), Radar (`#radar`, live funding), Apps (`#hub`), Safety (`#safety`), Install (`#install`), FAQ (`#faq`) and the footer.
- **Live data.** The funding board, the agent window's live answer and the reopen board read the Arcus and Lighter public APIs from the browser every 60 seconds. Both allow any origin, so no server of ours sits in between.
- **Hero.** 120,000 points (60,000 on phones) sampled from the brand print and stored in `public/hero-points.bin` as little-endian uint16 x/y pairs, drawn with Three.js. It renders only while it is on screen and the tab is visible, at a device pixel ratio of at most 1.5.
- **Plates.** `public/plates/*.webp` are white ink on transparency, used as CSS masks, so one file draws both ink layers. Each prints in through a halftone screen as it scrolls into view, and loads only once it comes near the viewport.
- **Strings.** Every visible string in `index.html` has a `data-i18n` key, and `src/i18n.js` holds the same keys in 12 languages (en, zh, zh-TW, ko, ja, vi, tr, ru, es, pt, fr, de). A new string needs a translation in every language.
- **Reopen table.** `src/gaps.js` is generated by `scripts/gaps.py`; see [ARCHITECTURE.md](../ARCHITECTURE.md#the-gap-table).
- **Font.** Satoshi loads from Fontshare. Its licence allows web use but not redistributing the files, so they are not in this repository.
